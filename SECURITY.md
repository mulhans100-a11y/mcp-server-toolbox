# Security Policy

## Supported versions

Security fixes are provided for the latest release on the default branch. When reporting an issue,
include the affected version or commit.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option on this repository's **Security** tab so the
maintainers can review the report privately. Include the affected tool, the expected impact, and
clear steps to reproduce it. Avoid posting exploit details or sensitive log samples in a public
issue.
